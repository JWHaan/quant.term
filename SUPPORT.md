# Support

`quant.term` is community-maintained and does not provide guaranteed response times.

- Reproducible defects: use the [bug report template](https://github.com/JWHaan/quant.term/issues/new?template=bug_report.yml).
- Feature proposals: use the [feature request template](https://github.com/JWHaan/quant.term/issues/new?template=feature_request.yml).
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md) and report privately.

Before opening an issue, run the latest `main` branch, check browser console and network errors, and identify which provider or panel is affected. Never post API keys, private keys, seed phrases, or personal data.
